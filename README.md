# 🎙️ Voxa Flow – AI Voice Agent Platform

An AI-powered voice agent platform designed to enable natural voice-based interactions using modern web technologies and Large Language Models (LLMs).

## 🚀 Overview

Voxa Flow is a MERN-stack-based AI voice agent platform that combines speech processing and AI capabilities to create interactive voice experiences.

## ✨ Key Features

- AI-powered voice interactions
- Speech-to-Text (STT) and Text-to-Speech (TTS)
- LLM-based conversational responses
- User authentication using JWT
- Dashboard for managing voice agents
- Conversation history management
- Embeddable AI assistant
- REST API integration

## 🛠️ Tech Stack

**Frontend:** React.js, JavaScript, HTML, CSS

**Backend:** Node.js, Express.js

**Database:** MongoDB

**AI Integration:** OpenAI API / Gemini API

**Authentication:** JWT

**Communication:** REST APIs

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/RitamMani/AI-Voice-agent-platform-voxa-flow-.git
```

2. Navigate to the project directory:

```bash
cd "ai voice agent"
```

3. Install frontend dependencies:

```bash
cd Client
npm install
```

4. Install backend dependencies:

```bash
cd ../Server
npm install
```

5. Configure environment variables in your server `.env` file.

6. Start the application using the scripts defined in the respective `package.json` files.
